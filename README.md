# 🌐 Prosty Projekt HTML/CSS

To jest podstawowa wersja statycznej strony wykonanej z użyciem czystego HTML i CSS.

## 🛠️ Użyte technologie

- **HTML5** – struktura strony
- **CSS3** – proste style (brak responsywności, layout desktopowy)
- Brak frameworków, bibliotek JS ani preprocesorów

projekt/

└── style.css ← arkusz stylów
